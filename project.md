# Бабушка Анна — Описание проекта

## Что это

Лендинг-страница для AI-персонажа «Бабушка Анна» — виртуального народного целителя из Туркменистана.
Посетитель проходит короткий квиз (4 вопроса о симптоме, длительности, возрасте и что уже пробовали),
после чего Claude AI генерирует персональный народный рецепт от лица бабушки.
Цель — собрать аудиторию и направить её в Telegram-бот и Telegram-группу.

---

## Для кого

Русскоязычные люди 40–65 лет, интересующиеся народной медициной и натуральными рецептами.
Основная аудитория — женщины из диаспоры (Германия, Израиль, США, Австрия) с ностальгией по
«бабушкиным методам» и умеренным недоверием к официальной медицине.

## Техническая архитектура

- **Деплой:** Vercel (автодеплой из GitHub main)
- **API:** `api/ask.js` — Vercel serverless function → Anthropic Claude Haiku → персональный рецепт
- **Правило:** каждая страница — один самодостаточный HTML-файл (CSS + JS внутри, никаких внешних зависимостей, никаких CDN)
- **Языки:** RU / EN / DE (переключатель в шапке, переводы в JS-объекте i18n)
- **Аналитика:** Vercel Insights (script.js)

## Стиль дизайна

**Текущий стиль:** «Старая книга трав» — пергаментный, тёплый, аналоговый.

| Элемент | Значение |
|---------|---------|
| Фон | `#f5edd5` (пергамент), `#faf4e4`, `#fff8ec` |
| Текст | `#1a2e12` (тёмно-зелёный) |
| Акцент | `#B0892D` / `#9b3a10` (золото и терракот) |
| Типографика | Georgia, Times New Roman — serif, «книжный» |
| Hero-фон | Видео с тёмным overlay |
| Секции | Чередуются пергаментный / светло-серый |

**Оригинальный план (в design doc):** тёмная тема `#0a0a0a`, оранжевый акцент `#f97316` —
как в CLAUDE.md. В процессе разработки дизайн сменился на пергаментный стиль.
