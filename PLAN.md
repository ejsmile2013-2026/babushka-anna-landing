## Что выяснили про конкурентов

Изучили 6 похожих продуктов: HerbalMedicine.ai, Herbalogi.ai, Care/of, Noom, Bright Moon Wellness, Dr. Axe.

**Что у них работает и нужно взять:**
- Квиз как первый шаг — снижает порог входа (уже есть ✓)
- Счётчик пользователей в hero — создаёт доверие
- История основателя/персонажа — самый сильный триггер доверия
- Один CTA, без выбора — меньше выбора = больше конверсия
- FAQ закрывает возражения до того, как они возникли

**Типичные ошибки в таких нишах (избегаем):**
- Перегруженный дизайн — отпугивает аудиторию 40+
- Слово «лечит» / «излечивает» — юридический риск (никогда не писать)
- Нет доказательства: красивые слова без одного реального отзыва = ноль доверия
- Много CTA — куда идти непонятно, человек уходит

## Возможные ошибки при редизайне — проверять сразу

### Технические — могут сломать сайт
- [ ] Квиз не работает (кнопки не переключают шаги) — проверить после каждого изменения JS
- [ ] API не отвечает (рецепт не генерируется) — открыть DevTools → Network, проверить `/api/ask`
- [ ] Появился внешний CDN или `<link>` на сторонний ресурс — нарушает главное правило
- [ ] Картинки не загружаются (babushka.png, видео) — проверить пути к файлам
- [ ] Переводы EN/DE не обновлены для новых секций — проверить переключатель языка

### Дизайн — могут сломать внешний вид
- [ ] Цвета не из пергаментной палитры (--bg, --accent, --gold, --herb) — проверить CSS-переменные
- [ ] Шрифт загружается с Google Fonts — запрещено, только Georgia/serif через CSS
- [ ] Кнопки меньше 48px высотой на мобиле — проверить на 375px
- [ ] Параллакс работает на мобильном (должен быть отключён при ≤768px)

### Текст — юридические и репутационные риски
- [ ] Написано «лечит» или «излечивает» — заменить на «помогает», «облегчает»
- [ ] Написано «гарантирует результат» — убрать, нельзя гарантировать здоровье
- [ ] Нет дисклеймера «не заменяет врача» в результате квиза

### Перед публикацией — финальная проверка
- [ ] Открыть на телефоне 375px — всё читается, кнопки нажимаются
- [ ] Пройти квиз до конца — рецепт генерируется и выглядит правильно
- [ ] Переключить язык EN и DE — нет пустых строк
- [ ] Открыть в Chrome и Safari — нет визуальных различий
